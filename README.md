
# 🚀 Quick Translate Chrome Extension

  ![icon-removebg-preview](https://github.com/user-attachments/assets/4f0555fb-6016-4e64-bcad-8488adf80c47)

**Instant translation at your fingertips**  - Highlight text and get translations in a click!

## 🌟 Features

-   ⚡  **Lightning-fast**  translations using Google Translate API
    
-   🌍  **38 languages**  supported
    
-   🖱️  **Smart detection**  - shows translation icon only when needed
    
-   📝  **Works in input fields**  with special paste functionality
    
-   🎨  **Clean, intuitive interface**
    

## 🛠 Installation

1.  Download the extension files
    
2.  Open Chrome and navigate to  `chrome://extensions/`
    
3.  Enable "Developer mode" (toggle in top-right corner)
    
4.  Click "Load unpacked" and select the extension folder
    

## 🎮 How to Use

1.  **Highlight text**  anywhere on a webpage
    
2.  Click the  **🌐 icon**  that appears
    
3.  View translation in the popup
    
4.  For input fields: Click  **Paste**  to insert translation

## 🌐 Supported Languages

-   Vietnamese, English, Chinese, Japanese, Korean
    
-   French, German, Spanish, Italian, Russian
    
-   And 28 more languages! (See full list in popup)
    

## ⚙️ Configuration

Click the extension icon to:

-   Set source/target languages
    
-   Save your preferences
    

## 🐛 Known Issues

-   May not work on some complex websites
    
-   Limited to ~5000 characters per translation
    

## 💡 Tips

-   Use  `Esc`  key to close translation popup
    
-   The icon automatically positions itself to avoid screen edges
